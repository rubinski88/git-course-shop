# Магазин электроники

Статическая учебная витрина для курса Git.

## Как открыть

Откройте index.html в браузере. Сервер и база данных не нужны.
Страница shipping.html содержит условия доставки.
Страница budget.html показывает товары до 5000 рублей.

## Что проверить

- В каталоге четыре товара: Lenovo IdeaPad 3, LG UltraGear 27, Logitech M280 и Logitech K120.
- У монитора LG UltraGear 27 указано "Нет в наличии".
- Доставка по городу стоит 450 рублей.

## Локальные файлы

.env и notes.local.txt остаются на компьютере и не входят в историю.
.env.example показывает состав учебных настроек. Страница их пока не читает.
